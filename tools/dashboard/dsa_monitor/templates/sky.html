Static-sky continuum monitor

Fleet-combined dirty image of the static-sky mean (the ~1 s sliding boxcar each corr node subtracts before the burst search). One frame every ~30 s, greyscale, stretched −3σ…+10σ where σ is a robust (MAD) per-image noise estimate. Frames are 2× oversampled (UV zero-padding — exact band-limited interpolation, same FOV) and pillbox grid-corrected so edge sources show at true relative strength. The RA/Dec graticule assumes the meridian phase center (α₀ = LST, δ₀ = obs dec); NVSS sources ≥ 100 mJy inside the field are listed beside the image. North up, east right. If bright continuum sources are not visible here, the search is not seeing the sky. Manual refresh only. Frames live under {{ sky_root }}.
