## Hook (Phase 6b) — production wire-in

The injector is invoked **after `unpack_int4_split`** and **before
the RFI flagger** in
[`_process_block_corr_phase`](../src/dsart/services/corr_fast_integration.py).
That insertion point exercises the full downstream chain
(RFI → cal → GEMM → grid → coarse-DM → static-sky → transport →
search) on injected pulses, so recovery tests measure the same
pipeline that real bursts travel.

```text
fada raw bytes
   │
   ▼ unpack_int4_split
voltages_real / voltages_imag (GEMM layout)
   │
   ▼ ★ ctx.injector.apply_block(real_v, imag_v, block_specnum_start)  ← Phase 6 hook
   │
   ▼ RFI flag → voltage zero-fill
   ▼ apply_cal_split (F21 DEC-phase fold)
   ▼ FastCorrKernel.compute_split (Stokes I)
   ▼ Stage-1 multi-DM coarse dedisp + gridder
   ▼ StaticSkyEMA
   ▼ TransportTX → search
```

### Surface

#### `FastIntegrationConfig.inject_configs: tuple[InjectionConfig, ...]`

Default `()`. When non-empty, `build_context` constructs an
`OnlineInjector` for the chgroup with the loaded antpos and queues
each config via `add_pending`. The injector is reused for the
lifetime of the service.

#### `IntegrationContext.injector: OnlineInjector | None`

Default `None`. When `None`, the hot path has zero overhead (one
`is None` test per block).

#### CLI: `--inject-spec <JSON>` (repeatable)

Pass a JSON dict matching
`InjectionConfig.to_json()`. Repeat for multiple simultaneous
injections.

```bash
python -m dsart.services.corr_fast_integration \
    --fada-key fada --device cuda:0 --chgroup 0 \
    --obs-dec-deg 53.85 --apply-cal /path/to/cal.dat \
    --dm-plan-path /home/ubuntu/proj/dsart/configs/dm_plan_N8_dmmin100_tol1.6_v2.npz \
    --chan-sum-factor 8 --t-int-fast-native 8 \
    --inject-spec '{"inj_id":"phase6_extragal","l_rad":0.0,"m_rad":0.0,
                    "dm_pc_cm3":500.0,"fluence_jy_ms":50.0,
                    "width_samples":32,"profile":"gaussian",
                    "apply_at_specnum":20480}' \
    --inject-spec '{"inj_id":"phase6_galactic","l_rad":0.02,"m_rad":0.01,
                    "dm_pc_cm3":20.0,"fluence_jy_ms":100.0,
                    "width_samples":64,"profile":"gaussian",
                    "apply_at_specnum":40960}'
```

`apply_at_specnum` is referenced to **service start**: one block =
2048 specnums = 4096 native samples, so an injection at
`apply_at_specnum=20480` fires at block-counter `n = 10`. Allow a
few blocks of orchestrator/Triton-JIT warmup before the first
target.

### Sign + dispersion conventions

- Phasor: `exp(+2πi · ν_ch · (E_a·l + N_a·m + U_a·n)/c)` (POSITIVE
  sign — DSA-110 SNAP voltage convention; pinned by
  `test_F22_visibility_phase_matches_lm_target`).
- Dispersion: cold-plasma law referenced to `NU_TOP_PROC_GHZ`
  (peak at the top-of-band channel arrives at
  `apply_at_specnum * 2` native samples; lower channels delayed
  by `K_DM · DM · (ν_ch⁻² − ν_top⁻²)` ms).
- Intrinsic profile: `gaussian` (unit-area over
  ±`MAX_WIDTH_SAMPLES`) or `boxcar` (unit-area, divide by width).
  Peak amplitude scale `√(fluence_jy_ms / width_samples)`.

## Tests (Phase 6 wiring)

[`tests/test_corr_fast_integration.py`](../tests/test_corr_fast_integration.py)
adds five Phase-6-suffixed cases:

1. `test_phase6_build_context_no_injector_when_configs_empty` —
   default config keeps `ctx.injector is None` (zero overhead pin).
2. `test_phase6_build_context_builds_injector_from_configs` — one
   `InjectionConfig` yields a populated `OnlineInjector` whose
   chgroup, device, and dtype match the integration context.
3. `test_phase6_build_context_accepts_multiple_configs` —
   `--inject-spec` repetition is honoured.
4. `test_phase6_inject_modifies_voltages_in_corr_phase` — at the
   block whose native window overlaps the peak, the Stokes-I cube
   differs from the no-injection baseline.
5. `test_phase6_inject_no_op_outside_target_block` — at a far block
   (n=200), the cube is bit-identical to the no-injection baseline
   (footprint-skip / auto-purge pin).

Plus the existing 17 `OnlineInjector` acceptance tests in
[`tests/test_online_injector.py`](../tests/test_online_injector.py)
continue to pass — they cover the dispersion math, phasor sign
convention, fluence scaling, GPU vs CPU bit-identity, etc.

   Galactic injection (`dm_pc_cm3=20`) drives the
   `bright_galactic` branch in the C2 classifier (i.e. fires the
   12 σ trigger with `dm_galactic_fraction < 0.75 · gal_dm_max`).

Each item is a one-shot run; results land in
