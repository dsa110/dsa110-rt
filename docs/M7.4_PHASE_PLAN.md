   summary commit on `m7/c1c2-coincidencer` that touches this file.
2. If a phase is split or merged, leave the canonical numbers intact and put
   the rationale in this file — do not renumber.
3. When pivoting due to an operator instruction (e.g. "skip 0319"), record the
   instruction date + operator and mark the phase **SKIPPED** rather than
   deleting it.

   stays scannable.
